## When task-checkpoint is unavailable

Use this variant only if no established runtime/store is available. Do not replace or
bypass an existing lease. Save this handoff and a manifest of regular artifact paths and
SHA256 hashes through the available file tools; reread both and verify the actual files.
Keep private state outside distributable source. The source writer must finish/reconcile
jobs and explicitly yield at a safe boundary. Record the single intended receiving writer.
If exclusive cooperating ownership cannot be established, stop dependent writes and say
what user action is needed. A document cannot fence unrelated writers.
